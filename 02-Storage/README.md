# Module 2 — Storage

**Exam weight:** 15–20%

Storage is one of the most reliable, oldest, and most-used services in Azure. Almost every workload — VMs, App Service, AI, analytics — touches storage somewhere.

> Think of this module as the **warehouse and filing cabinets** of your Azure skyscraper. Some things go in giant container halls (blobs), some in shared file rooms (Azure Files), some on FedEx-style fast queues (Queues), and some in catalog ledgers (Tables).

## Learning outcomes

- Choose the right storage account type and redundancy
- Configure blob lifecycle, tiers, and immutability
- Mount Azure Files on Windows/Linux
- Lock down storage with network rules, private endpoints, and identity-based access
- Generate Shared Access Signatures (SAS) safely
