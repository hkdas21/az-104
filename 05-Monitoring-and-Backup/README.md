# Module 5 — Monitoring & Backup

**Exam weight:** 10–15%

The final module — and arguably the most "operational" one. After you've built things, you must:
- **Watch** them (metrics, logs, alerts)
- **Protect** them (backup, restore)
- **Recover** them when disaster strikes (Site Recovery)

> Treat this module as the **CCTV cameras, smoke detectors, and insurance policy** of your Azure skyscraper. Boring on a good day, lifesaving on a bad one.

## Learning outcomes
- Configure Azure Monitor metrics, logs, and alerts
- Use Log Analytics with KQL to query telemetry
- Set up Application Insights for app monitoring
- Use Network Watcher tools to troubleshoot connectivity
- Protect VMs, files, and databases with Azure Backup
- Plan disaster recovery with Azure Site Recovery
