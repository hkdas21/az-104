# Module 1 — Identity and Governance

**Exam weight:** 20–25%

This is the *foundation* of everything else in Azure. If you don't know who someone is (identity) and what they're allowed to do (governance), nothing else matters.

> Think of this module as the **security desk + HR department** of your Azure skyscraper. Before anyone gets near a server, a storage account, or a network, *this team* decides who walks in and what floors they can visit.

---

## Learning outcomes

By the end of this module you'll be able to:
- Explain the difference between Microsoft Entra ID and on-prem Active Directory
- Create users, groups, and bulk-import them
- Configure self-service password reset and MFA
- Build a hierarchy with management groups and subscriptions
- Apply Azure Policy to enforce rules
- Assign built-in and custom RBAC roles using least privilege

---

## Recommended order

1. Start with **Entra ID** — get the mental model right first.
2. Then **Users and Groups** — the day-to-day admin tasks.
3. **Subscriptions and Governance** — zoom out to how you organize.
4. **RBAC** last — it ties everything together.

Each file ends with a quiz. Don't skip them. The quizzes are designed to surface the exact corners that the exam loves to ask about.
