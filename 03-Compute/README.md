# Module 3 — Compute

**Exam weight:** 20–25%

This is where things get fun. Compute is **the workhorse** of any cloud platform — the actual servers running your applications. You'll learn VMs first (the heavyweight), then how to make them resilient, then alternatives like App Service and containers.

> Compute is where most candidates already have intuition from on-prem days. The trick is learning the *Azure-flavored* twists: managed disks, scale sets, App Service plans, AKS.

## Learning outcomes
- Provision Windows and Linux VMs in the portal and CLI
- Configure managed disks, NICs, and extensions
- Use availability sets, zones, and scale sets for HA
- Deploy a web app to App Service and configure deployment slots
- Run containers in ACI and AKS
