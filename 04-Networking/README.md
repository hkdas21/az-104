# Module 4 — Networking

**Exam weight:** 15–20%

Networking is where most candidates lose marks. The concepts seem simple individually, but the exam loves to combine them — *"what happens when an NSG blocks port 443 but a route table sends to a firewall?"* — and you need to trace traffic step by step.

> Treat this module as the **plumbing, hallways, elevators, and roads** of your Azure skyscraper. Without it, no one gets between rooms, and no one gets in or out.

## Learning outcomes
- Design VNet address spaces and subnets
- Connect VNets via peering and gateways
- Secure traffic with NSGs, ASGs, and route tables
- Distribute traffic with the right load balancing tier
- Connect on-prem to Azure with VPN / ExpressRoute
- Configure DNS and name resolution
